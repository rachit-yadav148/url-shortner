# URL Shortener (Go)

This is a simple URL shortener built using Golang.  
The project helps understand how to build basic REST APIs, handle HTTP requests, and implement redirect logic in Go.


## What this project does

- Takes a long URL and generates a short version
- Stores the URL mapping in memory
- Redirects the short URL to the original one
- Exposes APIs that can be tested using Postman or Hoppscotch


## Technologies Used

- Go (Golang)
- net/http package
- MD5 hashing
- encoding/hex
- Postman / Hoppscotch for testing
